# diederikdijkstra.nl

Persoonlijke site gebouwd met Eleventy.

## Ontwikkelen

Installatie:

```bash
npm install
```

Lokale ontwikkeling:

```bash
npm run dev
```

## Build

Volledige productiebuild:

```bash
npm run build
```

## Projectdocumentatie

- `docs/mapbox-structure.md`
- `docs/feed-content.md`
- `docs/feed-examples.md`

## Belangrijke mappen

- `src/feed/` - feed-items in markdown
- `src/includes/` - templates, data en providers
- `src/js/` - frontend scripts
- `src/css/tw/` - Tailwind styles
- `src/lib/` - utility code en shortcodes
